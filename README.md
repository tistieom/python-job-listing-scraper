# python-job-listing-scraper
The [Python Job Listing Scraper](https://roadmap.sh/projects/job-listings-scraper) project from roadmap.sh.

The scraper when run will scrape [Fake Python](https://realpython.github.io/fake-jobs/) and create a `data.csv` file. Each job's title, company, location, and link to the job listing will be written.

It uses the `csv`, `requests`, and `bs4` modules.

The `data.csv` file created when running this code is also given.

To run, download `scraper.py` and run `python scraper.py` in terminal.
